只读盘点为主，未改产品代码、未动数据库。本次审阅不重复 09-07 日的技术复测

## 一、立项立意（DESIGN.md 第 1 章原文）

- **一句话定义**：「人生规划系统是一个陪伴用户从高中到职场早期的 AI 数据伙伴。」
- **核心用户**：中国高中生(15–18) + 家长 + 大学生(18–22)。
- **核心场景（MVP v1.0 只做 4 个）**：选科决策 → 考试错题分析 → 志愿填报 → 大学规划 → 求职准备。
- **核心价值主张**：用「数据 + AI」替代高价真人咨询；差异化 = **数据从高中开始积累，越用越准**（对标夸克「只有推荐、不存历史」）。
- **明确边界**：
  - P1/v2.0 暂不做：大学课程、考研、语音、可穿戴、社交网络分析、求职/职业咨询。
  - 明确不做：小学/初中、心理健康诊断（需医疗资质）、金融投资建议（需金融牌照）、中年/晚年场景。

## 三、核心落差（立意 ↔ 落地）

### 落差 1：范围膨胀——从「4 场景」到「20 域人生全景」
立意把 v1.0 钉死在 4 个场景，并把**家庭 / 社交 / 亲密 / 旅行 / 心理 / 兴趣 / 意义**
放进「愿景层，非当前优先级」，把**心理健康诊断、金融投资**列为「明确不做」。
现场却已全部建成独立模块（`psychology`/`finance`/`family`/`social`/`intimacy`/`travel`/`meaning`/`interest`），
且是真实 CRUD 而非占位。范围的扩张发生在核心未熟之时：4 场景里「求职/职业」「大学规划」
的 AI 能力与数据积累尚未坐实，边缘场景反而先长满。

### 落差 2：护城河是空的——「越用越准」当前为 0 行
立意把「数据从高中开始积累」作为唯一护城河与商业差异化的根基。
现场 live 库 40 张表 **0 行**：无用户、无积累轨迹；README 宣称的 51k 分数线 / 2.5k 大学
静态数据也未落入库（仅存于 seed 脚本与 pipeline 目录）。「越用越准」的机制没有任何一条
可复算的运行证据。

### 落差 3：AI 是纸面上的灵魂，运行态是空壳
一句话定义里产品是「AI 数据伙伴」，核心手段是「用 AI 替代真人咨询」。
现场 AI 封装是真实且规范的（`ai_client.py` + 5 模块挂接：ai_coach/college/daily_tracker/exam/recommend），
但 key 默认空，未配置时不是降级到 rule-based 替代，而是直接返回占位句子。
因此演示态下产品的灵魂不工作，用户拿到的核心价值是「未配置」文案。
另：`AI_MODEL` 默认值 `claude-sonnet-4-6` 需核对是否为有效模型号。

### 落差 4：文档是立项时快照，未跟随现场
README 写「6 模块 / 34 路由 / 14 页 / 60 测试」，现场是 20 模块 / 108 路由 / 28 页 /
97+ 单测 + 29 E2E。文档没有跟着 8 批视觉改动与模块化重构走。

## 四、做得扎实的地方（诚实对照，不以偏概全）

- **工程卫生有纪律**：9 月 7 日那轮技术复测（`REVIEW-2026-09-07.md`）确认单测 97、E2E 27、
  六路由同源 200、封存 users=0 全部通过；mypy 0 错。
- **架构在演进**：模块化单体（20 域发现式加载 + manifest + Alembic 基线化 + 003 收敛 40 表 parity）
  说明团队没有停在 demo 脚手架，门禁/parity 意识在线。
- **后续批次一致守信**：最近 8 批视觉改动全部「隔离 E2E 全绿 + 生产 users=0 + 端口回收」，
  并诚实记录了一次 E2E_API 漏设导致的沾污与一次 pkill 自杀式回收。

这些是「工程质量」上的稳，不是「立意推进」上的进。

## 五、定性判断

> 系统的**叙事立意**（从高中到职场的 AI 数据伙伴，靠长期数据越用越准）
> 与**实际落地**（20 域人生全景 CRUD、AI 空壳、数据 0 行）之间存在根本性错位。

它现在更接近「人生全景的 CRUD 记账本」，而不是 DESIGN 里写的那句「AI 数据伙伴」。
最近 8 批工作都在打磨愿景层页面的观感（家庭/社交/亲密/旅行/心理/兴趣/意义），
这些页面做得再精致，也不贡献立意的两个承重柱——**AI 分析**和**长期数据积累**，
而这两根柱子目前都是空的。

一句话：**工程在横着长（铺全景），立意要竖着长（做深 4 场景的 AI + 数据）。**
